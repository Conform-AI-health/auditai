# Security and Responsible Disclosure

AuditIA's public repository contains portfolio documentation only and should not contain credentials, patient-identifiable information, confidential employer material, production data, or security-sensitive implementation details.

If you believe you have identified accidental disclosure of sensitive information, a privacy concern, or a safety/security issue related to material in this repository, please contact the repository owner privately.

Please do not publish sensitive details, personal data, credentials, or exploit information in a public GitHub issue.

This policy is a responsible-disclosure request and does not create a bug-bounty program or promise compensation.
